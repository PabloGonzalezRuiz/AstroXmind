# Bandeja de entrada de convocatorias

Ubicación reservada para PDF oficiales de convocatorias. **Todavía no está activa la automatización.** No subir archivos personales o listados nominales: esta rama es pública. Cuando se implemente EST-01A, bastará añadir un PDF con cualquier nombre y confirmar el commit para que se identifique y proponga su nombre canónico y metadatos. Ver [contrato](../../../docs/estudio/03-ingesta.md).
