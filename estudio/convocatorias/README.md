# Expedientes de convocatorias

Salida futura del proceso de ingesta: un directorio por identidad documental, originales inmutables, derivados por fases y metadatos. No hay expedientes publicados todavía.

Cada expediente contendrá `00-fuente/` (archivo recibido protegido y excluido de índices), copia canónica F00, manifiesto YAML y derivados F01–F05. La carpeta tendrá la identidad canónica sin sufijo de fase. Ver [contrato](../../docs/estudio/03-ingesta.md). No subir aquí archivos sin validar privacidad.
