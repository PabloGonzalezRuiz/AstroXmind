# AstroXmind — instrucciones para agentes

Antes de trabajar, leer `docs/09-continuation.md`, `docs/04-project-status.md`, `docs/03-roadmap.md` y `docs/00-master-prompt.md`. Verificar siempre el HEAD real, el contenido del repositorio y los resultados de CI; no asumir que la documentación es prueba de implementación.

Reglas: registrar cada tarea como AST-NNN, documentar decisiones con ADR, conservar evidencias de commits y pruebas, diferenciar planificado/implementado/verificado, no cerrar tareas sin criterios de aceptación, no publicar releases ni modificar otros repositorios sin autorización. Al terminar cada actividad actualizar estado, registro de tareas y continuidad. Si faltan datos, declarar la incertidumbre. Fuente de verdad: Git y resultados verificables.

Fase 0: documentación y auditoría. Fase 1: Astro + Starlight básico. La integración PMD/XMind es posterior; no incorporarla a la versión inicial.
