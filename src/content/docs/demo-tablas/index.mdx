Esta sección contiene **prototipos**, no contenido legislativo oficial. Se han construido con Markdown, HTML y MDX, sin bibliotecas adicionales.

- [Tabla árbol vertical plegable](./arbol-vertical/): niveles y apartados desplegables.
- [Tabla árbol horizontal](./arbol-horizontal/): estructura en columnas inspirada en XMind.
- [Comparativa de formatos](./comparativa/): tabla Markdown, detalles HTML y componentes de estudio.

**Objetivo:** comprobar qué representación funciona mejor para estudiar y qué sintaxis resulta más fácil de generar automáticamente con IA.

> La exportación a XMind no forma parte de estas pruebas; primero se evalúa la representación en la web.
