# Tabla árbol nativa desde MDX

Esta página prueba una ruta alternativa: dentro de `<TreeTable>`, la jerarquía se escribe con listas Markdown anidadas. Los guiones crean los nodos y la sangría define su nivel; no se necesitan encabezados `#` para los elementos del árbol. El componente la representa como HTML estático con spans calculados en el servidor. Los encabezados `#` siguen sirviendo para organizar el documento.

<TreeTable>

- TablaArbol
  - Nodo1
    - Nodo1Subnodo1 con **énfasis**
    - Nodo1Subnodo2
  - Nodo2 con [una referencia](#criterio)
    - Nodo2Subnodo1
      - Nodo2Subnodo1Subnodo1

</TreeTable>

### MD base de la tabla

Esta lista es el contenido que se transforma en celdas: cada guion inicia un nodo y cada nivel de sangría añade un nivel jerárquico. No hace falta escribir la tabla HTML, usar `#` para los nodos ni calcular sus spans. El componente admite aquí listas sin ordenar con guiones.

```md
- TablaArbol
  - Nodo1
    - Nodo1Subnodo1 con **énfasis**
    - Nodo1Subnodo2
  - Nodo2 con [una referencia](#criterio)
    - Nodo2Subnodo1
      - Nodo2Subnodo1Subnodo1
```

### Cómo ver el MDX en crudo y editarlo

Astro muestra el resultado compilado en la wiki; el archivo fuente se edita por separado. Abre el enlace **ver el código fuente** para leer el MDX completo o **editar el archivo** para cambiarlo en GitHub. El archivo está en `src/content/docs/demo-tablas/tabla-arbol-mdx.mdx`.

Si quieres probar cambios sin tocar el repositorio, abre el [laboratorio StackBlitz](https://stackblitz.com/fork/github/PabloGonzalezRuiz/AstroXmind/tree/main/examples/astro-component-lab?startScript=dev). Ese laboratorio edita su propio `src/pages/index.mdx`; no modifica automáticamente esta página de la wiki. Para cambiar esta prueba, edita el archivo MDX de arriba.

## Criterio de prueba

El árbol tiene ramas de distinta profundidad y etiquetas con formato en línea. Así se puede revisar el alineado de las celdas, las clases por nivel y la conservación de negrita y enlaces. El prototipo no sustituye el procesador Markdown actual.
