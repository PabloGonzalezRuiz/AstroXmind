## Qué estamos evaluando

La estructura horizontal es útil para comparar **tema → título → artículo → apartado**. Los paneles se pueden plegar, pero este prototipo no redistribuye automáticamente las celdas como XMind al cerrarlos.

## Sintaxis de origen

```html
<div style="display:grid;grid-template-columns:1fr 1fr 2fr">
  <div>Tema</div>
  <details><summary>Título</summary>...</details>
  <details><summary>Artículo</summary>...</details>
</div>
```

**Conclusión provisional:** para producción convendría encapsular este patrón en un componente `TreeTable`, evitando que una IA tenga que escribir el CSS.
