# Galería Pandoc para legislación

Esta galería muestra **vistas HTML interactivas dentro de Astro/Starlight** y la **sintaxis Pandoc** que puede alimentar un futuro conversor. **Importante:** las interacciones de esta página no son funcionalidades nativas de Pandoc: los desplegables usan HTML, las pestañas son de Starlight y una tabla árbol ordenable necesitará JavaScript adicional. Pandoc transforma Markdown en HTML y permite añadir clases, identificadores y atributos.

## 1. Secciones de una ley plegables

<details open>
  <summary><strong>Título preliminar · Disposiciones generales</strong></summary>
  <details>
    <summary>Artículo 1 · Objeto</summary>
    <p>Texto de demostración, no una transcripción legal.</p>
  </details>
  <details>
    <summary>Artículo 2 · Ámbito de aplicación</summary>
    <p>Texto de demostración, no una transcripción legal.</p>
  </details>
</details>
<details>
  <summary><strong>Título I · Derechos y obligaciones</strong></summary>
  <p>Contenido de ejemplo plegable por título.</p>
</details>

**Fuente declarativa propuesta (Pandoc):**

```markdown
::: {.ley #norma-ejemplo theme="legislacion" view="accordion"}
# Norma de ejemplo
## Título preliminar
### Artículo 1
Texto del artículo.
### Artículo 2
Texto del artículo.
:::
```

El bloque `:::` y los atributos son sintaxis Pandoc; `view="accordion"` es una convención propia que necesitaría un filtro para generar los elementos `details`.

```markdown

:::
```

Pandoc admite tablas Markdown y estilos mediante clases. **Ordenar columnas y plegar filas requiere código de interacción**, por ejemplo Tabulator, AG Grid o un componente propio.

Las clases se convierten en atributos HTML que podemos estilizar con CSS. El contenido normativo debe provenir de una fuente oficial y mostrar fecha de actualización.

## 5. Un único Markdown, dos destinos

```markdown
::: {.arbol #ley-demo view="tree-table" theme="oposiciones-azul" xmind-layout="logic-right"}
# Ley de ejemplo
## Título preliminar
### Artículo 1
### Artículo 2
## Título I
### Artículo 3
:::
```

**Web:** un filtro transforma las declaraciones en componentes HTML interactivos. **XMind:** otro exportador interpreta los mismos nodos y atributos y crea un archivo `.xmind`. Estos filtros todavía no están implementados en esta galería.

## 6. Qué necesitamos para renderizar Pandoc de verdad

1. Instalar Pandoc en el proceso de compilación (por ejemplo, en GitHub Actions).
2. Convertir archivos fuente con `pandoc -f markdown+fenced_divs+header_attributes -t html5`.
3. Aplicar una hoja CSS de temas y filtros para las vistas `accordion`, `tree-table` y XMind.
4. Integrar el HTML generado en Astro, sin interpretar HTML arbitrario de fuentes no confiables.
5. Probar las vistas en móvil y automatizar la exportación a XMind.

Esta página es una **galería funcional de interfaces y ejemplos de sintaxis**, no una prueba de que Pandoc ya esté instalado en el proyecto.
