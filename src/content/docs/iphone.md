## Añadir el icono

1. Abre [AstroXmind privada](https://astroxmind-pablo.mixedclef8.chatgpt.site) en Safari.
2. Inicia sesión con la misma cuenta de ChatGPT propietaria de la wiki si se solicita.
3. Pulsa Compartir y selecciona Añadir a pantalla de inicio.
4. Conserva el nombre AstroXmind, activa Abrir como app web si aparece y pulsa Añadir.

Ahora puedes abrir la wiki desde su icono. No necesitas una aplicación de la App Store.

## Acceso y conexión

Esta edición usa el acceso privado del alojamiento: disponer del enlace no concede permiso para leerla. El repositorio de GitHub también sigue privado.

Requiere conexión a Internet. Esta versión no añade caché sin conexión ni un service worker. Al abrir el icono, el sistema puede solicitarte de nuevo iniciar sesión.
