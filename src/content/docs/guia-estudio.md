Los temas se mantienen como archivos Markdown en `src/content/docs/`. Cada archivo tiene un encabezado YAML con `title` y `description`.

## Flujo inicial

1. Abre un bloque desde el menú lateral.
2. Consulta el tema en la wiki.
3. Para corregir contenido en esta fase, edita su archivo Markdown en GitHub y guarda el commit.
4. GitHub Actions comprobará la compilación cuando esté configurado.

La edición desde la propia wiki, la generación de XMind y la sincronización visual **todavía no están implementadas**.

## Calidad del temario

Contrasta siempre legislación y convocatorias con fuentes oficiales. Los ejemplos actuales son marcadores de posición, no apuntes completos.
