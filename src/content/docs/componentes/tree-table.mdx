# TreeTable · tabla jerárquica

La jerarquía se escribe como una lista Markdown anidada dentro del componente. Los guiones crean nodos y la sangría define cada nivel. TreeTable calcula las celdas y genera HTML estático durante la compilación.

<TreeTable>

- Raíz
  - Rama A
    - Elemento A.1 con **énfasis**
    - Elemento A.2
  - Rama B con [un enlace](#clases-por-nivel)
    - Elemento B.1
      - Elemento B.1.a

</TreeTable>

## Clases por nivel

Cada celda recibe una clase CSS `nivel-N` según su profundidad. En este ejemplo, la raíz usa `nivel-0`, sus ramas usan `nivel-1` y los elementos descendientes reciben niveles consecutivos. El componente aplica estas clases para que el estilo pueda definirse una vez y reutilizarse.

### MD base de la tabla

Cada guion inicia un nodo. La sangría añade un nivel jerárquico. No hace falta escribir la tabla HTML ni calcular los spans.

```md
- Raíz
  - Rama A
    - Elemento A.1 con **énfasis**
    - Elemento A.2
  - Rama B con [un enlace](#clases-por-nivel)
    - Elemento B.1
      - Elemento B.1.a
```
