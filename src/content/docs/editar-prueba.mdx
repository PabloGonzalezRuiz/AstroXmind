## Editar Markdown

En **Acciones**, elige **Editar documento** para abrir el archivo completo a pantalla completa. Puedes alternar entre Markdown, Dividido y Resultado. El modo de lectura muestra la página publicada y el menú permite consultar su código fuente y su historial.

## Guardado en GitHub

Abre **Configuración** en la cabecera y guarda un token limitado a AstroXmind con permiso Contents de lectura y escritura. Pulsa **Editar documento**, modifica el archivo y pulsa **Guardar**. El editor escribe directamente en `main` y GitHub Actions publica la wiki después de compilarla. El enlace al commit confirma el guardado; la página publicada tarda lo que dure el despliegue. La vista previa representa Markdown, y los componentes MDX se renderizan en la compilación de Astro.

## Crear componentes desde Markdown

Abre **Acciones → Editar documento**, selecciona la lista completa siguiente y pulsa **Crear → Tabla jerárquica** (también puedes usar clic derecho o Mayús+F10 sobre la selección). Comprueba el resultado en directo y el import automático. Ctrl+Z deshace ambos cambios a la vez. No necesitas guardar para probarlo.
