## Editar Markdown

Cambia un título o una celda de la tabla. **Resultado** se actualiza mientras escribes. En una pantalla estrecha puedes alternar con **Editar** y **Resultado**.

<WikiEditor />

**Guardar borrador** lo conserva en este navegador. Puedes descargar el Markdown para llevarlo a otro equipo. Esta prueba admite Markdown con tablas. La vista fiel de componentes MDX, como TreeTable, requiere una fase posterior.

## Guardado en GitHub

Abre **Configuración** en la cabecera o el enlace Configuración de GitHub del editor. Guarda allí un token limitado a AstroXmind con permiso Contents de lectura y escritura. Se conserva en este navegador y el editor se conecta automáticamente. Tras modificar el texto, pulsa **Guardar en GitHub** y abre el enlace al commit. El editor escribe en `editor/drafts`, en el archivo `editor-drafts/preview.md`. Usa texto de prueba, porque el repositorio es público. Si el guardado falla, pulsa **Abrir borrador de GitHub** para recuperar la revisión. Desde Configuración puedes reemplazar o eliminar el token.
