## Editar Markdown

Cambia un título o una celda de la tabla. **Resultado** se actualiza mientras escribes. En una pantalla estrecha puedes alternar con **Editar** y **Resultado**.

<WikiEditor />

**Guardar borrador** lo conserva en este navegador. Puedes descargar el Markdown para llevarlo a otro equipo. Esta prueba admite Markdown con tablas. La vista fiel de componentes MDX, como TreeTable, requiere una fase posterior.

## Guardado en GitHub

Genera un [token de acceso personal de grano fino](https://github.com/settings/personal-access-tokens/new) para el repositorio AstroXmind con permiso Contents de lectura y escritura y caducidad corta. Introduce el token únicamente en el campo **Token** y pulsa **Guardar token**. Se conserva en este navegador y al volver a la página se conecta automáticamente. Tras modificar el texto, pulsa **Guardar en GitHub** y abre el enlace al commit. El editor escribe en `editor/drafts`, en el archivo `editor-drafts/preview.md`. Usa texto de prueba, porque el repositorio es público. Si el guardado falla, pulsa **Abrir borrador de GitHub** para recuperar la revisión. **Olvidar token** elimina la credencial guardada; úsalo en equipos compartidos. El token persistente es accesible al JavaScript del mismo origen.
