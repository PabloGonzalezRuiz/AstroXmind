# AstroXmind · Laboratorio de componentes

Aplicación Astro mínima para editar y probar componentes aislados con vista previa en vivo y errores del compilador. Se abre en StackBlitz desde la wiki.

```sh
npm ci
npm run dev
```

`src/components/TreeTable.astro` es la fuente del prototipo; la página `src/pages/index.mdx` proporciona el caso de prueba. La wiki reutiliza este mismo componente desde su página experimental. La copia abierta en StackBlitz es un entorno de prueba; los cambios que hagas allí no modifican automáticamente el repositorio.
