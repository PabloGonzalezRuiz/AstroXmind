# Ejemplos para conversión a XMind

Esta carpeta reúne casos de referencia con el Markdown de entrada, el archivo `.xmind` resultante y el JSON de XMind cuando está disponible. Sirve para comparar la jerarquía de origen con `rootTopic`, `children.attached`, `structureClass` y los estilos exportados.

- [TablaArbol](./TablaArbol/): prueba de tabla árbol con encabezados Markdown y una lista anidada.

La regla de herencia de valores y el diseño del lenguaje están documentados en [docs/11-xmind-json-defaults.md](../../docs/11-xmind-json-defaults.md).
