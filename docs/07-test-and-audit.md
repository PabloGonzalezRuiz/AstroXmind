## Protocolo de auditoría

2. Comparar el contenido con `04-project-status.md` y `05-task-register.md`.
3. Comprobar enlaces relativos y referencias.
4. Para código futuro: ejecutar formato, lint, tests, build y comprobar artefactos.
5. Registrar comandos, commit, entorno, resultados y limitaciones en `docs/audits/`.
6. No declarar `PASS` sin evidencia.
