# ADR-001 — Arquitectura inicial

Fecha: 2026-11-14. Estado: aceptada.

**Contexto:** se necesita un proyecto de estudio TAI independiente del conversor experimental existente.

**Decisión:** comenzar con Astro + Starlight y Markdown, estabilizar la wiki antes de añadir editor, PMD o visor XMind.

**Alternativas descartadas por ahora:** integrar todo desde el inicio; reutilizar el repositorio del conversor.

**Consecuencias:** menor complejidad inicial, pero integración posterior y posibles migraciones por diseñar.
