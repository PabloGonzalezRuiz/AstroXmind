# Visión y alcance

AstroXmind es un entorno de estudio TAI que comenzará como wiki estática navegable y buscable. Los temas se escribirán principalmente en `.md`; `.mdx` se reservará para componentes que requieran interactividad.

## Evolución deseada
Wiki estable → contenido TAI revisado → editor Markdown con persistencia → adaptador PMD/XMind → visor XMind integrado → sincronización al guardar.
